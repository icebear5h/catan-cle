# Generated SFT Data

Regenerable SFT datasets live here rather than under the installable `sft/`
package.

- `atlas_topology/`: deterministic text-only atlas rows.
- `node_factors/`: generated contracts, annotations, images, and visual QA.
- `legacy_pilots/`: historical subsets retained for provenance only.

The generated payloads are ignored by Git. Rebuild commands and leakage rules
are documented in `sft/README.md`.
