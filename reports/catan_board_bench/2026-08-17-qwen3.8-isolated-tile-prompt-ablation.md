# Qwen3.8-27B isolated-tile prompt ablation

Execution date: 2026-08-19

The artifact directory retains the `20260817` experiment identifier chosen when
the run was planned.

## Question

Do Qwen3.8's isolated Catan tile errors primarily reflect visual perception,
incomplete class instructions, brief visual descriptions, or literal
angle-bracket wrappers such as `<WOOD>`?

The earlier probe was not a clean closed-class visual test. Its system prompt
showed only `<WOOD>` and `<ORE>` as resource-token examples. On 102 isolated
tiles, it scored 32/102 with canonical labels and 67/102 after mapping
`FOREST→WOOD`, `WOOL→SHEEP`, and `GRAIN→WHEAT`. The run also mixed OpenRouter
providers.

## Design

The 102 current images associated with the same historical sample IDs were
frozen. The historical run did not persist image hashes, so byte-for-byte
identity with its then-generated images cannot be proven.

The current set contains:

- five resources;
- ten production numbers per resource;
- two renderer-position variants per resource/number pair;
- two desert images.

All four conditions enumerate the complete six-class vocabulary. Two factors
were crossed:

1. label serialization throughout the prompt and response:
   - angle-wrapped: `<WOOD>`;
   - plain: `WOOD`;
2. guidance:
   - labels only;
   - labels plus brief renderer-specific color and icon descriptions.

The four conditions were:

- `angle_labels`
- `plain_labels`
- `angle_described`
- `plain_described`

The non-description prompts differ only in literal class wrappers. The same is
true of the two description prompts after removing `<` and `>` characters.
Class order, task wording, output rules, image bytes, and request settings were
otherwise fixed.

The descriptions were:

- WOOD: green tile with an evergreen tree;
- BRICK: orange-red tile with stacked brick blocks;
- SHEEP: yellow-green tile with a white sheep;
- WHEAT: golden-yellow tile with wheat stalks;
- ORE: gray tile with rocks;
- DESERT: beige tile with a cactus.

This is prompt-assisted closed-set classification. The description effect
bundles color and icon cues and adds prompt tokens. It does not measure an
unaided vision encoder or isolate color from shape.

Angle brackets are literal punctuation in this experiment. They were not
registered as tokenizer special tokens.

- Model: `qwen/qwen3.8-27b`
- OpenRouter provider: exactly `AkashML`
- Provider fallbacks: disabled
- Reasoning: explicitly disabled
- Temperature: 0
- Concurrency: 1
- Calls: 408, one per image/condition pair
- Scorer: `strict_tile_label/v2`
- Output API schema constraint: none

The evaluator locks the QA file, every source row, every image, all four
prompts, every job, and the transitive scorer implementation. It pre-reads and
rehashes all pending image bytes before the first request and records the hash
of the bytes actually submitted. Admission requires the exact model, provider,
prompt, image, scorer, stop reason, and zero reasoning.

The primary scorer preserves raw response text. It rejects surrounding
whitespace, lowercase labels, aliases, code fences, prose, wrong wrappers,
extra tokens, and desert-plus-number outputs.

- 0 reasoning tokens

## Factor effects on this fixed grid

Using strict pair accuracy:

- angle minus plain: `-0.98` percentage points;
- descriptions minus labels only: `+1.96` percentage points;
- interaction: `0.00` percentage points.

Direct paired discordances were:

- plain labels versus angle labels: 1–0;
- plain described versus angle described: 1–0;
- angle described versus angle labels: 2–0;
- plain described versus plain labels: 2–0.

These are tiny fixed-grid differences. Exact two-sided McNemar p-values are
1.0 for each 1–0 contrast and 0.5 for each 2–0 contrast. They do not establish
a population-level wrapper or description effect. The images reuse the same
terrain art across numbers and only two placement variants, and there is one
service realization per condition.

Operationally, angle wrappers provided no accuracy benefit. They increased
provider-reported prompt tokens by 2.0% without descriptions and 2.7% with
descriptions. They increased completion tokens by about 30% and cost by about
5.5% in both guidance conditions.

Descriptions increased prompt tokens by about 30% and cost by about 26%. On
this already easy isolated grid, they bought two additional strict answers per
wrapper style.

## Interpretation

The old 32/102 canonical and 67/102 alias-aware results were not a defensible
ceiling on isolated tile vision. Once the prompt enumerated the complete closed
class set, Qwen reached 97–98% strict exact without descriptions. Brief visual
descriptions raised that to 99–100%.

The historical-to-current jump cannot be attributed solely to vocabulary
enumeration: the system/user framing, output contract, provider control, and
service realization also changed. The controlled 2×2 result supports narrower
claims:

1. Literal angle wrappers are unnecessary for this task and slightly less
   efficient.
2. A complete plain vocabulary is almost sufficient for the synthetic isolated
   tiles.
3. Brief renderer-specific descriptions repair the remaining repeated BRICK-4
   confusion in this run.
4. Production-number reading is effectively saturated on large isolated
   assets.
5. The earlier FOREST/WOOL/GRAIN behavior is consistent with a prompt
   vocabulary and canonicalization problem, not failed number OCR. This design
   did not isolate vocabulary enumeration from framing, provider, service
   realization, and other prompt changes.

This does not repair the previously observed 0/31 exact node-occupancy result
or the weak dense-board grounding result. Those are separate visual primitives
and localization tasks.

## Decision

For this model-facing visual classifier, prefer plain canonical values such as
`WOOD`, `BRICK`, and `SHEEP`, then convert them to any engine-specific display
syntax outside the model. Do not spend tokens on angle wrappers unless another
interface requires them. Typed JSON may be tested separately; this experiment
did not test it.

The described plain condition achieved 102/102 on this fixed grid in one
service realization. Treat that as observed saturation of this narrow probe,
not a population-level vision ceiling. It can advance one diagnostic rung
without making the broad board suite harder. The next visual diagnostic should:

1. retain the complete plain class vocabulary;
2. place several actual Catan tiles in one spatial layout;
3. ask for resource-number pairs by visible location;
4. then remove location labels and ask balanced neighbor questions;
5. keep node buildings and roads as separate probes.
